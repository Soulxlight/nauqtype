Nauqtype compiler

Usage:
  nauqc <command> [options]

Commands:
  check <source> [--diagnostics text|json]
  emit-c <source> [-o <output>]
  facts <source> [--format v1|v2|v3]
  review <source> [--format v1|v2]
  review-diff <before> <after> [--format v1|v2]
  change-report <before> <after> [--policy <policy>] --format v1|v2
  refactor-rename <source> <stable-id> <new-name>
  policy-check <source> <policy-path>
  fmt [--check] <source>
  build <source> [-o <output>]
  run <source> [-o <output>]
  test
  prove
  prove-seed <stage1-c> <stage2-c>
  prove-selfhost
  prove-corpus
  help, --help, -h
  version, --version, -V

No arguments preserve the legacy selfhost bootstrap mode.
