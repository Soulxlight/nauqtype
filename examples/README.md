# Nauqtype Examples

This directory contains the canonical examples for Nauqtype.

To understand how these examples are organized by feature and lesson progression, please see the [Teaching Corpus](../TEACHING_CORPUS.md) index at the repository root.

**Note:** Runnable entrypoints are locked by `prove-corpus`, while every `.nq` file in this directory, including helper-only modules, is locked by the formatter gate. Do not move or remove them without updating `selfhost/proof.nq` and `TEACHING_CORPUS.md`.
